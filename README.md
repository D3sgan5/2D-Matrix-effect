# 2D-Matrix-effect
  This repository is for Roblox Studio.

  So. I made 2D Matrix Rain Effect. It is pretty simple but might be useful for someone.
  There is 2 scripts. One is making the effects with loop and second is with TweenService
  
  To setup and see/use it all you need is:
  1. Downolad
  2. Paste rbxm file in Baseplate/Your place in Roblox Studio
  3. Place the "Matrix Effect" frame in ScreenGUI in StarterGui
  4. Press Play
  5. Done

The logic behind is pretty simple. 
I just take the particle, take the size of it and depending on person screen counting how many i can put of partile in it.
Then i just copy the Particle, call it streamer and copy a bit more to create a trail effect.
And a bit of Random with offset so it looks more natural.
